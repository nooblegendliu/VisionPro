# 采集模块节点进度

## 图像源

**软件主流程已验收，实机能力部分完成。** 最近核对日期为 2026-11-26。图像源是采集模块完成重写的第一个节点，工具 ID 为 `visionpro.image.source`，配置版本为 1。原有的本地读图、相机主动取帧和接收相机帧三个入口已合并。旧方案加载或导入子图时会迁移，切换来源后下游仍可沿用原有主图绑定。[节点设计与迁移说明](../design/image-origin-node.md)

| 范围 | 已完成并验证的内容 |
| --- | --- |
| 本地图像 | 支持添加图片和文件夹、按选中项运行、自动切换、末张停止、方案存图和目录订阅。桌面连续读取同一张 12×10 Mono8 图像，SN 从 1 增至 2。[本地参数窗口](../design/image-source-parameters.png) |
| 相机 | 支持关联全局相机、主动取帧和使用本轮输入帧。模拟相机 SIM-001 实测得到 2×2 Mono8 图像；三路分时频闪及同时启用 Mono8 时的输出规则已用模拟设备验证。[相机参数与模块结果](../design/image-source-camera-parameters-updated.jpg) |
| SDK | 支持由 VisionPro C++ 宿主向流程送帧，已验证缓冲区复用和重复投递处理。桌面送入 9×9 彩色 BMP 后，同时得到 BGR8 主图和 Mono8 灰度图。[SDK 参数与模块结果](../design/image-source-sdk-results-updated.jpg) |
| 公共参数与模块结果 | 已实现 SN、灰度输出、Y 向拼接、触发清空和字符过滤。结果可按调用查看、绑定全局或局部变量，并复制 C++ 取值表达式。桌面实测将图宽 12 写入全局变量「图宽」，将文件名写入流程局部变量「图名」。[桌面验证记录](../development.md#1-当前阶段) |

**回归记录**　Windows x64 Release 启用 Qt、OpenCV 和 MVS，全量 CTest 通过 180/180 项。完成情况复核时另行重跑图像源、宿主送帧、模拟相机、结果读取和桌面交互等 9 项相关测试，全部通过。[验收用例与设备边界](../design/image-origin-node.md#7-验收用例)

## 输出图像

`visionpro.image.output` v1 从「图像采集」工具箱添加。双击节点，在「基本参数」选择底图，在「渲染设置」勾选前序结果。运行后工作台、历史和下游节点可读取同一份标注图。原图、渲染图可单存或双存，也可按工件 OK／NG 分流。[节点设计与验收记录](../design/image-output-node.md)

| 存图方式 | 配置及产物 |
| --- | --- |
| 本地 | 为勾选的图种选择目录和文件名前缀。支持 BMP、JPEG、PNG，可按日期建目录，并设置容量、保留期和覆盖方式。 |
| FTP | 配置远端地址、编码、目录与账号，用「校验连接」验证指定目录能写入。在线时可直接上传。需要离线补传时，为对应图种配置本地缓存目录，补传成功后删除缓存。 |
| 多节点大文件 | 在「设置 → 采集策略」启用后，各节点共用打包目录。原图和渲染图各有包路径及条目名称。在「工具 → 存图大数据解压」中导入可预览，拖入单包直接解压，也可选目录批量解压。CLI 提供 `archive-list` 和 `archive-extract`。 |

「全部保存」可不绑定判定，图像写入普通目录；「仅 OK／NG」可绑定判定枚举、整数 1／0 或字符串 OK／NG。在流程图像页选择「双画面对照（1×2）」可同时查看原图与合成图。节点自身写入失败时，错误分支可订阅模块状态 0，并另外选取图像源保存现场图。

2026-11-26 的 Windows x64 Release 全量 CTest 通过 187/187 项，覆盖本地、真实回环 FTP 和多节点归档。项目 `.dat` 支持逐张找回和内容校验，海康原厂工具的互读性尚待真实样包核对。[复现命令](../development.md#1-当前阶段)
