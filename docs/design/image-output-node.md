# 输出图像节点设计

「采集 → 输出图像」选取方案中的一张图像，可将多个前序模块的检测结果叠加在图上，输出结果图，也可根据条件保存原图和渲染图。VisionPro 以海康《VisionMaster 算法开发平台用户手册 4.4.3 Lite》为功能依据，包括 FTP 存图、多节点大文件存图及配套的预览和解压。

第 1–6 节说明手册中的操作、参数和结果，引用均为印刷页码。VisionPro 已实现该节点。第 7 节记录项目接口，第 8 节给出逐项验收及仍需原厂样例核对的细节。[海康手册 §13.1.3，第 314–318 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=328) · [VisionPro 图像源节点设计](image-origin-node.md)

## 1. 节点用途与操作示例

输入可以是全局相机取得的图、本地加载的图，也可以是图像处理模块的输出。「原图」以本节点选定的输入为准。例如，输入源选了图像增强结果，保存原图就保留该增强图。渲染图在选定底图上呈现配置的文字和前序检测结果。节点窗口分为「基本参数」「渲染参数」「渲染设置」。[节点用途与参数分组，第 314 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=328)

海康手册的电池片示例展示了三个独立选择。

1. 双击「输出图像」，在「基本参数 → 输入源」选择「图像源 1.图像」，确定底图。
2. 在「渲染设置 → 前项存储设置」订阅「几何创建」，把计算得到的电池片定位框画到底图上。
3. 在运行界面的多图像控件中，将第二个画面绑定到「输出图像 1 → 输出图像」，即可查看该节点的结果。第一个画面可以单独选图像源和测量线，在同一轮检测中查看另一组标记。

存图条件另行绑定。例如，生产时可以持续输出标注图，只在检测结果为 NG 时保存该件产品的原图和渲染图。[电池片配置，第 72–74 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=86) · [运行界面图 4-35 至 4-37，第 76–78 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=90)

## 2. 基本参数与条件存图

### 2.1 输入、输出和存图开关

| 参数 | 用户可配置的行为 |
| --- | --- |
| 输入源 | 选择方案中图像源的图像或其他模块处理后的图像。 |
| 输出使能 | 开启时输出图像，关闭时停止图像输出，可减少模块耗时。 |
| 存图使能 | 默认关闭，此时模块仅提供图像输出功能。开启后可在输出图像的同时按配置保存文件。 |
| 保存渲染图／保存原图 | 两项可分别开启，也可同时开启。要实际存图，至少开启一项，并为每个启用项设置文件名前缀。 |
| 触发保存 | 默认关闭。开启存图并选好图种后，关闭触发即可自动保存。打开触发后，根据触发变量和保存条件决定哪些图落盘。 |
| 触发变量 | 一般绑定前序条件检测的结果，作为判断 OK／NG 是否命中保存条件的依据。 |
| 像素格式 | 可选 `RGB24` 或 `MONO8`。对应输出结果的整型枚举见第 6 节。 |

手册明确给出了「存图使能」和「触发保存」的默认值。输出使能的初值，以及关闭输出使能后单独开启存图的组合行为，列入第 8 节版本核对项。[基本参数，第 314–315 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=328) · [命名和像素格式，第 316–317 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=330)

### 2.2 触发保存的四种条件

| 保存条件 | 触发结果与文件行为 |
| --- | --- |
| 全部保存 | 保存所有图像，图种取决于「保存原图」「保存渲染图」的勾选。 |
| OK 时保存 | 触发变量为 OK 才保存。已选原图及渲染图的文件名均含 `OK`。 |
| NG 时保存 | 触发变量为 NG 才保存。已选原图及渲染图的文件名均含 `NG`。 |
| 不保存 | 即使原图和渲染图都已勾选，也不生成图像文件。 |

触发变量描述被检测工件的判断结果。「模块状态」描述输出图像节点自身的状态，列在模块结果中。[保存条件，第 314–315 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=328) · [模块状态，第 318 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=332)

### 2.3 目录、文件名与存图缓存

| 参数 | 生效条件和规则 |
| --- | --- |
| 渲染图路径／原图路径 | 关闭触发保存，并开启对应图种时可设置。全部渲染图写到渲染图路径，全部原图写到原图路径。 |
| 渲染 OK／NG 路径、原图 OK／NG 路径 | 开启触发保存和对应图种后可设置。原图、渲染图分别有 OK 和 NG 目录。两种图都启用时可以配置四个去向。 |
| 路径长度 | 手册以 Windows 默认路径限制 260 为背景，规定上述普通路径及 OK／NG 路径最长 255，超出会导致存图失败。 |
| 生成目录 | 启用后按月份和日期创建文件夹，图像进入对应的日期文件夹。 |
| 渲染图命名／原图命名 | 仅对应图种开启时可设置。两种图各自的文件名前半部分均可手填或从方案订阅，必须有值。后半部分可选「序号」「时间」「无」。 |
| 存图间隔 | 指触发存图时缓存的**图像张数**。最多 10 张，且不能超过对应图像缓存队列的上限。 |
| 渲染图缓存／原图缓存 | 配置各自存图队列可容纳的最大张数，渲染图和原图各最多 20 张。 |

例如，要将 NG 工件的两类图片交给不同人员复查，可开启触发保存、选择「NG 时保存」，分别设置「原图 NG 路径」「渲染 NG 路径」，再给两种图各设文件名前缀。检测得到 NG 时两个目录各新增相应文件，两份文件名均含 `NG`。[目录与间隔，第 315 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=329) · [命名与缓存，第 316 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=330)

## 3. 渲染参数与渲染设置

「渲染参数」决定**标注怎样画**，「渲染设置」决定**图上出现哪些结果和文字**。两组设置作用于结果图，工作台缩放属于查看操作。[渲染参数与设置，第 317–318 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=331)

| 分组与参数 | 选项及效果 |
| --- | --- |
| 渲染参数 · 图形倍率类型 | **原图尺寸**按原图尺寸、原线宽和原字号存储。**界面尺寸**保持图像宽高，线宽和字号按「原图宽度 ÷ 500 像素」等比缩放。**自定义倍率**分别按设置的线宽倍率、字宽倍率调整。 |
| 渲染参数 · 线型 | 4 连通线、8 连通线、抗锯齿线。 |
| 渲染设置 · 内容、颜色、字号、位置 X/Y | 选择要写在存储图像上的文本，设置颜色、字体大小及横纵位置。 |
| 渲染设置 · 前项存储设置 | 添加前项，订阅支持「结果显示」设置的前序模块，再逐个选择该模块哪些结果显示在最终输出图像上。可订阅多个模块，组合多个显示项。 |

前序模块通过自己的「结果显示」描述可显示的图形与文字，不同工具提供的结果项可不同。电池片示例选的是几何创建的定位框。输出图像节点应保留选择模块及其具体显示项的能力。[通用结果显示 §7.2.3，第 157 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=171)

## 4. 本地存储与 FTP

### 4.1 文件格式、容量与保留期

| 基本参数 | 规则 |
| --- | --- |
| 保存格式、图片压缩质量 | 可选 BMP、JPEG、PNG。选 JPEG 时可调压缩质量，值越大，压缩后的图像品质越高。 |
| 存储方式 | 达到最大存储数量或目标磁盘空间不足时，可选「覆盖存储」或「停止存储」。存图缓存张数和已归档文件数量分别管理。 |
| 磁盘剩余空间、存储单位 | 设置目标磁盘的剩余空间阈值，单位为 MB 或 GB。达到阈值时执行所选存储方式。低于阈值且选择覆盖存储时，尝试删除旧存图释放空间。 |
| 最大保存天数 | 设置到期自动删除，最长可保留 500 天。 |

手册的版本记录还注明 V4.2.0 增加了**同步存储**。4.4.3 Lite 的节点专章列出了存图缓存和容量处理规则，同步存储在该版本的设置入口和完成时机需要随实现核对。[本地存储，第 316 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=330) · [同步存储版本记录，第 18 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=32)

### 4.2 FTP 存储、断连与本地缓存

| 场景 | 手册规定的行为 |
| --- | --- |
| 配置与连接 | 打开「启用 FTP」，设置服务器 IP、端口、用户名、密码、编码格式和 FTP 路径，启用连接。可用连接参数旁的按钮校验连接状态。至少开启一种图的保存并配置其名称。 |
| 连接成功 | 将图像保存到指定 FTP 路径。远端路径不存在时自动创建。 |
| 连接失败 | 图像直接保存到本地，界面不显示上传失败提示。用户仍可主动校验连接状态。 |
| 连接成功且本地已有缓存图像 | 将本地缓存图像上传到指定 FTP 路径，上传后从本地删除这些缓存图像。 |

这里的本地缓存是可补传的图像文件。第 2.3 节的原图／渲染图缓存以张数限制存图队列，两者的验证方法不同。[FTP 参数与回退行为，第 316–317 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=330)

## 5. 全局采集策略与大文件存图

多节点高频存图由「设置 → 采集策略 → 大文件存图」统一管理。开启后，多个输出图像模块的待存图片达到固定数量时，统一压缩成一个本地 `.dat` 文件，减少磁盘写入频率。**全局设置的大文件路径接管各节点的存图路径。** 如果该目标磁盘空间不足，后续图像会无法存入指定路径。节点结果中的「大文件路径」用于定位产物。[入口，第 43 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=57) · [采集策略 §11.5，第 277 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=291)

配套「存图大数据解压工具」提供图像找回流程。海康的 `DecompressionTool.exe` 支持选择或拖入单个 `.dat` 文件，也可导入文件夹批量解压。导入后可预览包内图像。解压到 `.dat` 所在目录，勾选建立同名文件夹时写入对应子目录。[解压工具 §12.9，第 294 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=308)

## 7. VisionPro 实现约定

### 8.1 手册未明确规定时的 VisionPro 行为

| 组合或边界 | 本项目可观察到的结果 |
| --- | --- |
| 输出与存图开关 | 默认输出图像，默认关闭存图。关闭输出时，图像、宽、高和像素格式四项均标为未产生。启用的存图仍按条件执行。原图采用所选底图的像素，渲染图和发布图采用所选输出像素格式。 |
| 触发来源与全部保存 | 同一个触发输入可绑定判定枚举、整数 `1/0` 或字符串 `OK/NG`。「全部保存」可省略触发变量。有有效判定时用对应 OK／NG 目录，未绑定或未判定时用该图种的普通目录。「仅 OK／NG」遇到无效判定会给出诊断。 |
| 前项渲染 | 按来源模块选择显示项，每项可分别设 OK、NG、普通颜色、不透明度和线宽，使用该来源本轮调用的判定。旧方案沿用已有的颜色、线宽和掩膜混合比例。文本支持换行、判定色和独立样式。[无 GUI 成图](../../source/tools/vision/image_output_render.cpp) |
| 双画面对照 | 工作台的流程图像页可切换为 1×2。左右画面分别选择底图与叠加来源，可用左侧查看测量或检测标记，右侧查看输出节点已合成的像素。历史画面使用选中轮次和作用域的结果。画面选择在当前文档打开期间按流程记忆。[工作台结果页](../../source/ui/workspace_results.cpp) |
| 间隔、队列与同步 | 间隔按每个节点、每种图独立累计命中条件的图片，0 或 1 表示立即处理。达到张数后按入队顺序处理，满队列报告错误。默认开启同步存储。异步模式返回时只确认入队。CLI 结束、桌面显式完成队列写入时排空队列，并将不足一包的尾图写出。 |
| 大文件和 FTP 同时开启 | 全局大文件目录接管两种图的去向，可省略节点本地目录。每包默认 64 张，可设 1–65536 张。同次调用的双图若同包，两条逐图路径相同；若跨包，各自返回已发布包的路径。旧端口 `big_file_path` 继续指向本次收据中的最后一个已发布包。仍在凑包及异步入队的调用保留当时的未产生状态。 |
| 本地路径与名称 | 两个路径字段均为实际本地目录，文件名由各自的名称字段给出。FTP 上传成功时返回远端实际文件名，本地路径为空缺。断线回退时返回本地目录与名称，补传及删除不会改写旧调用的结果。 |
| FTP 与本地缓存 | 在线时直接上传已编码的图像，可省略本地目录。断线或服务器拒绝发布时，已配置的本地目录承担缓存；若同时缺少可写缓存目录，该次存图失败并保留诊断。校验连接会在指定远端目录内实际写入、发布并清理探测文件。 |
| 到期清理 | 会话运行期间检查节点已配置的原图、渲染图与 OK／NG 目录，重新打开方案后也可按索引清理。只删除仍在对应目录管理范围内、内容仍匹配的过期本地散图。未确认上传的缓存继续保留到补传成功。此保留期仅适用于本地散图。 |
| 模块状态与工件判定 | `module_status` 描述归档节点自身，成功为 1，失败或超时为 0。显式连接的错误分支可订阅这个整数，也可映射至结果变量。图像和文件等业务输出在失败时保持缺失，诊断保存在原调用。取消或跳过没有 0／1 判定。工件 OK／NG 单独读取上游检测结果。 |

上述默认值、组合行为和包格式是 VisionPro 的实现约定。VisionPro 包使用 `VPIMGDA1` 标识，逐项记录来源和文件名，单张编码图像上限为 512 MiB，提取时校验 SHA-256。海康 4.4.3 Lite 原厂客户端的对应默认值、队列时机及其解压工具与 VisionPro 包的互读性仍待原厂环境或样包核对。[运行与收据](../../source/tools/vision/image_output.cpp) · [归档服务](../../source/infrastructure/image_archive.cpp) · [包格式与提取](../../source/infrastructure/image_package.cpp)
