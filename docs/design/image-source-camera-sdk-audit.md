# 图像源桌面实测：相机与 SDK

2026-11-26，在 VisionPro 桌面版双击同一图像源节点，分别切换到相机和 SDK，再在配置好输入的测试方案中运行。下表中的页码为海康《VisionMaster 算法开发平台用户手册》4.4.3 Lite 的印刷页码。手册给出了关联相机示意图和两种来源的参数清单，未给出完整的 SDK 属性窗口截图，因此 SDK 对照以字段、显隐条件和操作入口为准。[相机参数，第 301–303 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=315) · [SDK 参数，第 303–305 页](../Manual/VisionMaster算法开发平台_用户手册_4.4.3Lite_20260515.pdf#page=317)

下方两表记录修改前的桌面行为，便于复现当时的差异。改版后，SIM-001 在默认窗宽下完成主动取帧，输出 2×2 Mono8，帧号和 SN 均为 1。SDK 通过流程输入接收 9×9 彩色 BMP，同时输出 BGR8 主图与 Mono8 灰度图。新版截图可同时查看参数、结果和变量绑定。[新版相机窗口及结果](image-source-camera-parameters-updated.jpg) · [新版 SDK 窗口及结果](image-source-sdk-results-updated.jpg) · [图像源节点设计](image-origin-node.md#21-流程画布和参数窗口)

## 验证边界
